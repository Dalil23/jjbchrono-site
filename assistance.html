Je n’entends pas les sons

  • Vérifie le volume de l’iPhone et, dans l’app, Paramètres → Sons.
  • Les signaux sonnent aussi en mode silencieux et écran verrouillé tant qu’une séance est en cours.
  • Avec un casque Bluetooth, le son s’arrête si le casque se déconnecte.

Débloquer JJB Chrono Pro

Paramètres → Passer à JJB Chrono Pro : achat à vie ou abonnement mensuel. Tu as reçu un code ? Touche « J’ai un code » sur la même page.

Restaurer un achat

Nouveau téléphone ou app réinstallée : ouvre l’écran Pro et touche « Restaurer les achats », avec le même compte Apple.

Résilier l’abonnement

Réglages de l’iPhone → ton nom → Abonnements → JJB Chrono. La résiliation prend effet à la fin de la période en cours.

Règles de compétition

Les règles affichées dans l’app résument le règlement IBJJF. En compétition, seul le règlement officiel de l’événement fait foi.
